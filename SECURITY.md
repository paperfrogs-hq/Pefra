# Security Policy

Pefra is in an early design and prototyping stage. There are no stable releases or security support commitments yet.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to Paperfrogs HQ at [hello@paperfrogs.dev](mailto:hello@paperfrogs.dev). Include a description, affected files or components, steps to reproduce, and the potential impact where possible. Do not include secrets or personal data in your report.

Please do not disclose a vulnerability in a public issue or discussion before the maintainers have had an opportunity to review it. Paperfrogs HQ will assess reports and coordinate any fix or disclosure as appropriate. No response or resolution timeframe is guaranteed at this stage.

For ordinary bugs and feature requests that do not involve a security issue, use the repository's GitHub issues.
