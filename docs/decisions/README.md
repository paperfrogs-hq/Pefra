# Design decision records

Record architectural and language-design choices here as numbered Markdown files. Each record should state its status, context, decision, alternatives considered, trade-offs, and consequences. Use `proposed` until the project owner accepts a significant language decision; record later changes in a new record and link to the earlier one. Keep accepted records, the specification, tests, and implementation consistent.

The first record, [0001](0001-implementation-language.md), documents Rust as the implementation language for the M0 workspace. It does not determine Pefra's own syntax, semantics, or safety guarantees.
